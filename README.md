# Test de QI

Tests de QI et exercices de logique : visuel, numérique, verbal, spatial, sur 3 niveaux.

**Jouer :** https://dynas-hub.github.io/test-qi/

- iPhone (Safari) : ouvrez le lien, touchez Partager puis « Sur l'écran d'accueil ».
- Android (Chrome) : ouvrez le lien, menu ⋮ puis « Installer l'application » (ou « Ajouter à l'écran d'accueil »).
- Une fois installée, l'app s'ouvre en plein écran et marche même hors connexion.

Le score affiché est indicatif : ce n'est pas un test de QI officiel.
